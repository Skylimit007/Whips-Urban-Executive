WHIPS URBAN EXECUTIVE - FORM EMAIL SETUP

Booking and contact forms send all named fields to:
nextedgeinnovations.org@gmail.com

The forms use FormSubmit.co AJAX and stay on the same page.
The customer sees a success/error message and is not redirected.

TESTING LOCALLY
1. Open Command Prompt.
2. cd /d "D:\Whips Urban Executive\Whips_Urban_Executive_Final\Cental"
3. Run: python -m http.server 8000
4. Open: http://localhost:8000/index.html
5. Open DevTools > Console. You should see:
   [Whips Urban Executive] Form handler initialized. Forms found: 2
6. Submit a booking. The Console should show the FormSubmit HTTP status and response.

IMPORTANT
- FormSubmit requires the receiving email address to be activated the first time.
- Check Inbox and Spam/Junk for the activation email.
- FormSubmit supports AJAX submissions cross-origin; local testing must still use a web server, not file://.
- After deployment, replace the local _url automatically generated by the script with the real page URL if you want exact production URLs in FormSubmit's records.

BOOKING FORM FIELDS
- Car type
- Pick-up location
- Drop-off location
- Pick-up date
- Pick-up time
- Drop-off date
- Drop-off time
- Phone number

CONTACT FORM FIELDS
- Name
- Email
- Subject
- Message
